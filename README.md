# AlSafwa Product Catalog 🚀

A modern, responsive web application designed as a digital catalog for AlSafwa's medical and laboratory products. Built with HTML, CSS, JavaScript, and Bootstrap 5, it focuses on performance, usability, and dynamic data management.

## ✨ Features

- **Dynamic Data Loading:** Products are securely and dynamically loaded from a local `products.json` file, ensuring adding new products is as easy as editing a text file without touching the core code.
- **Bilingual Real-Time Search:** Customers can search for products instantly using either English or Arabic names.
- **IFU (Instruction For Use) Integration:** Each product is linked to its unique PDF manual, which opens beautifully with a single click.
- **Smart Link Sharing Mechanism:** Utilizes the Web Share API to easily copy and share exact product PDF links. The links are heavily optimized and URL-encoded to ensure perfect compatibility with messaging platforms like WhatsApp.
- **Responsive & Premium UI:** Built with Bootstrap 5 and featuring modern design aesthetics (glassmorphism navigation, dynamic hover effects, and fallback SVG placeholders).

## 🛠️ Tech Stack
- HTML5
- CSS3 (Custom styles & glassmorphism)
- Vanilla JavaScript (ES6+ async/await fetch API)
- Bootstrap 5 (Styling & layout)

## 📦 How to Use
1. Clone the repository to your local machine.
2. Edit `products.json` to insert appropriate Arabic names and link the corresponding product images (`assets/images/...`).
3. Deploy to any static hosting provider (e.g., Vercel, GitHub Pages, Netlify).
